# stock-skills ChatGPT adaptation

This folder contains an importable ChatGPT Skill adapted from the stock-skills project. It is separate from the host repository's existing stock-analysis implementation.

Start with [`stock-investment-analyst.zip`](stock-investment-analyst.zip) to import the conversational Skill. See [`INSTALL.md`](INSTALL.md) for setup and capability limits, and [`INTEGRATION.md`](INTEGRATION.md) for the proposed API/MCP runtime boundary.
